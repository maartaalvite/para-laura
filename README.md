# Para Laura 💌

Una pequeña web interactiva, pensada primero para móvil, para hacerle a Laura una pregunta importante.

## Probarla en local

La web no necesita instalar dependencias. Basta con servir esta carpeta con cualquier servidor HTTP estático y abrir `index.html`.

Por ejemplo:

```powershell
npx serve .
```

## Publicación

El proyecto está preparado para publicarse directamente desde la rama `main` con GitHub Pages.
